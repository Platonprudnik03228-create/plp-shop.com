Регистрации (кто именно)

Аккаунты людей хранятся в отдельном сервисе входа. Список зарегистрированных открывается там:

Открыть список аккаунтов
Сейчас кнопки «Скачать» на сайте ведут прямо на файл, без регистрации. Поэтому скачивания выше — это все люди, а в списке аккаунтов только те, кто зарегистрировался сам. Чтобы видеть каждого скачавшего по имени/почте, скачивание нужно пустить через вход (см. ниже).

Почему просмотров много, а скачиваний мало — вероятные причины

  1. Ролики смотрят с телефона, а приложение ставится только на компьютер. Человек с iPhone нажимает «Скачать» и ничего не может сделать — и забывает.
  2. Нет пути «прислать ссылку на комп»: поле для почты на телефоне вернуло бы часть таких людей.
  3. Mac — только Apple Silicon (M1 и новее), и macOS пишет «не удалось проверить разработчика» — часть людей бросает на этом шаге.
  4. Нет счётчика визитов сайта, поэтому неизвестно, сколько из 30 тыс. зрителей вообще дошли до сайта.

Цифры скачиваний берутся из GitHub Releases (точные, считает сам GitHub). История по дням пишется автоматически каждые 2 часа.
